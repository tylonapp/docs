Uma feature agrupa os cards que entregam uma coisa ao longo do tempo.

## Como ler

<ParamField path="GET /v1/features" type="endpoint" />

<ParamField query="archived" type="string">
  `1` para incluir as arquivadas. Desligado por padrão: uma feature arquivada é
  uma que alguém decidiu parar de olhar.
</ParamField>

O `featureId` de [`PATCH /v1/cards/{number}`](/pt-br/api-reference/endpoints/cards)
vem daqui.

## Como escrever

Member, menos apagar.

<ParamField path="POST /v1/features" type="endpoint" />

<ParamField body="name" type="string" required>
  Até 60 caracteres.
</ParamField>
<ParamField body="description" type="string" />
<ParamField body="color" type="string" />

```json
{
  "id": "84842202542510070",
  "name": "Key rotation",
  "description": "",
  "color": "blue",
  "taskCount": 0,
  "doneCount": 0,
  "archived": false,
  "position": 0
}
```

`doneCount` contra `taskCount` é a leitura que vale colocar num painel:
ela conta cards que de fato chegaram ao fim do fluxo, não cards que alguém
marcou.

<ParamField path="PATCH /v1/features/{featureId}" type="endpoint" />
<ParamField path="DELETE /v1/features/{featureId}" type="endpoint" />

Apagar exige **maintainer**, igual na tela.
