Rascunhos. Um título, uma descrição, uma discussão, e nenhum Git — nada aqui
tem branch, porque iniciar um card é o ato deliberado que corta uma.

É uma lista e não uma coluna, e cresce sem limite: reordene, busque, escolha
de dentro dela.
