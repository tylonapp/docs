As etiquetas são do quadro, compartilhadas entre os projetos dele.

## Como ler

<ParamField path="GET /v1/labels" type="endpoint" />

Todas as etiquetas do quadro, com o id pelo qual um card é alterado.

```json
[
  { "id": "85098258082431403", "name": "api", "color": "blue", "taskCount": 10 }
]
```

`labelIds` em [`PATCH /v1/cards/{number}`](/pt-br/api-reference/endpoints/cards)
é o conjunto inteiro, então é daqui que o conjunto vem.

## Como escrever

Member, menos apagar.

<ParamField path="POST /v1/labels" type="endpoint" />

<ParamField body="name" type="string" required />
<ParamField body="color" type="string">
  Um dos nomes da paleta, não um valor hexadecimal.
</ParamField>

```json
{
  "id": "84842099970805746",
  "name": "needs-migration",
  "color": "amber",
  "taskCount": 0
}
```

<ParamField path="PATCH /v1/labels/{labelId}" type="endpoint" />
<ParamField path="DELETE /v1/labels/{labelId}" type="endpoint" />

Apagar tira a etiqueta de todos os cards de uma vez. `taskCount` é quantos
seriam — e é por isso que apagar exige **maintainer**, igual na tela.
